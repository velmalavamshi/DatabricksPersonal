# Client Assessment Report Template

## Report Structure

Every client assessment report follows this exact structure:

### 1. Executive Summary (1 page)
- Client name, industry, engagement date
- Overall maturity score (X.X / 5.0) and level name
- Top 3 findings (bullet points)
- Recommended engagement tier and estimated value

### 2. Current State Assessment (2-3 pages)
- Platform architecture overview
- Data maturity scores by dimension (table format)
- Strengths identified
- Gaps and pain points

### 3. Use Case Portfolio (1-2 pages)
- Identified use cases (scored using use_case_scoring.md)
- Priority matrix visualization
- Quick wins vs strategic investments

### 4. Recommended Roadmap (1-2 pages)
- Phase 1 (0-3 months): Quick wins + foundation
- Phase 2 (3-6 months): Core capabilities
- Phase 3 (6-12 months): Advanced / AI
- Dependencies and prerequisites

### 5. Investment & ROI (1 page)
- Estimated implementation cost by phase
- Expected annual value (savings + revenue + efficiency)
- Payback period
- Risk factors

### 6. Engagement Options (1 page)
- Option A: Assessment only (£15-25K)
- Option B: Assessment + Quick Wins (£40-75K)
- Option C: Full Transformation (£100-300K)
- Recommended option with rationale

## Tone & Style
- Professional, consultative (not salesy)
- Data-driven (every claim backed by evidence from assessment)
- Actionable (every finding has a recommended action)
- Honest (acknowledge gaps and risks, don't oversell)
