# Hologic Acronyms Glossary

Source: Hologic internal "Commonly Used Acronyms" list (Gen-Probe/diagnostics-lineage
document — several entries below reference Gen-Probe directly, reflecting Hologic's
acquisition history in molecular diagnostics). This is a **definitional reference**, not a
usage-preference list — it tells you what an acronym stands for, not which term to prefer in
writing. For preferred terminology, use the word-list tables in `terminology.md` (e.g., this
file defines both STD and STI below because both acronyms exist and are used in regulatory/
technical contexts, but `terminology.md`'s word list still governs which one to *write* in
Hologic content: **STI, never STD**, in body copy).

Pull this file in only when content actually touches assay, instrument, or regulatory
terminology — not needed for routine corporate writing.

## Notes

- A few acronyms above (**AE**) map to two unrelated terms — always confirm meaning from
  context before using or expanding one in a document, the same discipline the skill applies to
  Genie vs. Genius AI.
- This list carries clear diagnostics/molecular-testing lineage (Gen-Probe legacy terms, TIGRIS,
  APTIMA family) — it's the right file for lab/instrument/regulatory content, but not a general
  corporate-acronym list. For non-technical acronyms (QMS, AP, AMA), see the short table in
  `terminology.md` directly.
